# 试用排查

## 未出现 QuestBranch，或页面空白

确认插件已安装到当前启动的 profile，并在安装、更新后完整退出并重开该 profile。当前兼容基线为 DSH `0.2.1-rc.5`；安装成功不代表其他宿主版本已经兼容。提供错误信息时注明 Web 或桌面窗口。

## 没有模型，或模型调用失败

先在 DSH 自身完成模型、账号和工具配置，并用同一模型验证宿主原生对话。QB 从宿主读取模型与强度，不另行保存 API Key。保留厂商错误码与发生时间，分享日志前移除账号和令牌。

## 研究目录被占用

正常退出仍在使用该目录的旧 Host，再重新打开。不要在运行中删除锁文件，也不要让多个宿主或独立版 QB 同时直接写同一研究库。首次试用可按 README 创建独立目录和 profile。

## 导入研究后没有原生会话

研究 JSON 包含 QB 的结构、报告、来源和公开记录，不包含 DSH 账号、原生历史库或节点会话映射。完整备份需要在宿主退出后同时保留 QB 资料目录及 DSH 原生资料。新配置中恢复研究 JSON 后，会建立新的原生会话。

## 升级、回退与移除

先退出宿主并备份资料，再使用 DSH 官方插件管理入口更新或移除，完成后重启。移除插件会保留研究资料。不要为了升级重复执行 `--from-default-profile`，它会重置目标 profile；回退程序版本也不等于数据降级。

底部版本号打开的是 DSH 的插件管理。当前 `0.2.1-rc.5` 没有新版的 registry 版本列表；本地 `.tgz` 也不属于 registry 更新来源。没有版本列表不代表已是最新，请使用实际提供的新附件与校验文件。

如果刚刚强制结束 Host，确认旧进程已经退出后稍候再重开，等待目录锁过期。不要在运行中删除锁文件。安装失败或不兼容时保留具体错误，不能将它当作“没有更新”。

仍无法定位时使用[问题反馈](https://github.com/Ethan-decoy/QuestBranch-DSH/issues/new/choose)，提供版本、复现步骤与最小脱敏示例。
