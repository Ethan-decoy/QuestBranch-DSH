# QuestBranch for DeepSeek Harness

问之的 DeepSeek Harness 研究工作台扩展。目标是在 DSH 中用研究图组织问题、选择分支继续研究，并保留对话、阶段报告和来源关系。

**当前状态：仓库初始化，尚无可安装的插件、npm 包或 Release。** 插件入口、宿主适配与完整研究闭环仍在开发准备阶段；本仓库目前提供项目说明，不提供安装命令。兼容的 DSH 版本将在实际验收后列明。

## 产品关系

[独立版 QuestBranch](https://github.com/Ethan-decoy/QuestBranch) 与本扩展是同一研究产品的两种使用方式，复用研究核心。独立版提供自己的桌面与模型连接；扩展计划使用 DSH 的模型、工具、技能和原生会话，由 QB 管理研究结构、报告和来源。

QuestBranch owns the structure and continuity of exploration, not the authority of conclusions or execution.

## 本仓库的职责

本仓库承载经筛选的 DSH 插件源码、安装和升级说明、兼容性记录以及插件版本。开发在独立的私有开发仓库中进行；本仓库保持自己的提交历史，不同步开发仓库的内部研究记录、凭据或本机资料。

当前仓库保持私有，项目尚未指定开源许可证。插件仓库的建立不表示已发布，亦不表示已获 DSH 官方收录或背书。
